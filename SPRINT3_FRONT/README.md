Projeto desenvolvido para a Sprint 3 do Challenge FIAP 2026
A proposta do projeto é apresentar uma solução para tornar o uso da câmera do smartphone mais simples, inteligente e adaptado para diferentes situações do dia a dia.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- CSS Grid

## Sobre o projeto

A Landing Page apresenta:

- A solução
- Público-alvo
- Galeria
- Nossa equipe
- Contato
O projeto também foi desenvolvido com foco em responsividade para Desktop, Tablet e Mobile.
